crazy-ui is the React component library behind **crazy-hub** and the **Crazy Gothic Trainer**. It is built on
[Base UI](https://base-ui.com) primitives, styled with Tailwind CSS 4 and tailwind-variants, animated with
motion, and themed entirely through CSS variables.

## Principles

- **Tokens first.** Every colour, radius, shadow, font, density and duration is a `--cui-*` variable. An app
  restyles everything by overriding them — no forks, no `!important`.
- **Accessible by default.** Behaviour comes from Base UI; every colour pair is checked for WCAG contrast in
  the test suite.
- **Two ways to use a component.** Compound parts (`<Card.Root>`, `<Card.Title>` …) when you need control,
  and a short form when you don't.
- **Motion with restraint.** Short, eased, and switched off for people who prefer reduced motion.

## Examples

### Variants

`soft` (default) carries the accent, `solid` is the loudest, `outline` and `neutral` are for tags that shouldn't
draw the eye.

<ComponentPreview name="chip/variants" />

### Status

`success`, `warning` and `danger` tint the chip with a status colour — the same flags the trainer uses for test
results: verified, works badly, crashes. New features use the default `soft` chip.

<ComponentPreview name="chip/status" />

### Sizes

`sm` fits inside list rows and next to titles; `md` (default) is for standalone labels.

<ComponentPreview name="chip/sizes" />

### With an icon

Icons go inside the chip and are sized for you.

<ComponentPreview name="chip/with-icon" />

### Counts

A neutral small chip makes a quiet counter next to a tab or a heading.

## Accessibility

- A chip is plain text in a `<span>`; screen readers read it in line with what's around it.
- Don't rely on colour alone: the label says the status (“crashes”), the colour only supports it.
- A chip is not interactive. For a removable tag or a filter, put a `Button` next to it or use `Toggle`.

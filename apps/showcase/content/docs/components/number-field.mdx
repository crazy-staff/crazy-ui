## Examples

### Sizes

`sm`, `md` (default) and `lg` match the [Input](/docs/components/input) heights. The buttons sit inside the
field with a radius that follows the field's corner.

<ComponentPreview name="number-field/sizes" />

### Min, max and step

`min` and `max` clamp the value and disable the button at the limit. `step` is the size of one click or
arrow key; **Shift** uses `largeStep` (default 10) and **Alt** uses `smallStep` (default 0.1).

<ComponentPreview name="number-field/steps" />

### Formatting

`format` takes `Intl.NumberFormat` options — percent, fixed decimals, units, currency. `locale` sets the
separators. The value stays a plain number.

<ComponentPreview name="number-field/format" />

### Scrubbing

With `scrub`, dragging horizontally over the label changes the value, like in design tools. Without a label
a small handle appears at the start of the field. `hideButtons` leaves only the input.

<ComponentPreview name="number-field/scrub" />

### Disabled and read-only

`disabled` dims the field and its buttons. `readOnly` keeps the value selectable on a slightly darker fill.

<ComponentPreview name="number-field/states" />

### Inside a Field

Put it in a [Field](/docs/components/field) for a label, a description and validation; `Field.Label`
names the input and an invalid field turns the border red.

<ComponentPreview name="number-field/field" />

### Controlled

`value` and `onValueChange` control the number. It is `null` while the field is empty.

<ComponentPreview name="number-field/controlled" />

### Compound parts

Build the field yourself with `NumberField.Root`, `NumberField.Group`, `NumberField.Input`,
`NumberField.Decrement` and `NumberField.Increment` — here both buttons on the end with chevrons.

<ComponentPreview name="number-field/compound" />

## Accessibility

- Built on Base UI Number Field: the input is a text input with `inputmode="decimal"` (a numeric keyboard on
  phones and no native spinner buttons) and `aria-roledescription="Number field"`.
- **Arrow Up/Down** step the value, **Shift** and **Alt** change the step, **Home/End** jump to `min`/`max`.
- The buttons are named "Decrease" and "Increase" and are skipped by **Tab**; give your own buttons an
  `aria-label` in the compound form.
- Name the field with `label`, a `Field.Label`, or `aria-label`.

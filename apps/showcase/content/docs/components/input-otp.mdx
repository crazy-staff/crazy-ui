## Examples

### Separators

`groups` splits the slots, with a dash between groups. Pass any element to `separator` to change it.

<ComponentPreview name="input-otp/separator" />

### Letters and digits

`validationType` accepts `'numeric'` (default), `'alpha'`, `'alphanumeric'` or `'none'`;
`normalizeValue` can upper-case what is typed. `slotPlaceholder` hints at empty slots.

<ComponentPreview name="input-otp/alphanumeric" />

### Sizes

`sm`, `md` (default) and `lg` match control heights.

<ComponentPreview name="input-otp/sizes" />

### Controlled

`value` and `onValueChange` control the code; `onValueComplete` fires when every slot is filled.

<ComponentPreview name="input-otp/controlled" />

### Compound parts

Build the slots yourself with `InputOTP.Root`, `InputOTP.Group`, `InputOTP.Slot` and
`InputOTP.Separator` — here joined slots and `mask` for a hidden pairing code.

## Accessibility

- Built on Base UI OTP Field: each slot is an input; typing moves forward, **Backspace** back, arrows
  move between slots, and pasting fills every slot at once. The first slot has
  `autocomplete="one-time-code"`.
- Name the field with a `Field` label, a `<label htmlFor>` pointing at `id`, or `aria-label` (the short
  form wires it to the first slot). Other slots are named "Character 2 of 6" and so on.
- Separators have `role="separator"`.

## API Reference

### InputOTP

The short form. All Base UI `OTPField.Root` props pass through (`value`, `defaultValue`,
`onValueChange`, `onValueComplete`, `validationType`, `normalizeValue`, `mask`, `autoSubmit`, `name`,
`disabled` …).

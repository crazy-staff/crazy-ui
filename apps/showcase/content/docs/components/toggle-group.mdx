## Usage

```tsx
import { ToggleGroup } from '@crazy-staff/ui';
```

```tsx
<ToggleGroup
  defaultValue={['planned']}
  items={[
    { value: 'planned', label: 'Planned' },
    { value: 'done', label: 'Done' },
  ]}
/>
```

## Examples

### Sizes

`sm`, `md` (default) and `lg`. Items have the height of a [Toggle](/docs/components/toggle) of the same size;
the frame adds a little padding around them.

<ComponentPreview name="toggle-group/sizes" />

### Multiple

With `multiple`, any number of items can be pressed, each on its own soft accent fill. Here built from
`ToggleGroup.Item` children.

`iconOnly` makes every item square. Name each one with `aria-label`.

## Accessibility

- Renders a `<div role="group">` of `<button>`s with `aria-pressed`. Name the group with `aria-label`.
- <Kbd>Tab</Kbd> moves into the group, arrow keys move between items, <Kbd>Space</Kbd>/<Kbd>Enter</Kbd> press.
- The gliding fill is decorative (`aria-hidden`) and animates only `transform`; with reduced motion it jumps.
- If the items switch between panels of content, use [Tabs](/docs/components/tabs) instead.

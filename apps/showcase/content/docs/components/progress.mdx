## Accessibility

- Built on Base UI Progress: `role="progressbar"` with `aria-valuenow`, `aria-valuemin` and
  `aria-valuemax`; indeterminate bars leave out `aria-valuenow`.
- `label` (or `Progress.Label`) names the bar. Without one, pass `aria-label`.
- Use `getAriaValueText` when a percentage isn't the clearest way to say the value.
- The bar's movement turns off with `prefers-reduced-motion`.

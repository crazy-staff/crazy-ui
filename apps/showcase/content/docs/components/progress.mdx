```tsx
<Progress value={42} label="Downloading build 0.9" />
<Progress value={null} label="Preparing…" />
```

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number \| null` (`null` = indeterminate) | — |
| `label` | `ReactNode` | — |
| `showValue` | `boolean` | `true` with a label |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |

Parts: `Progress.Root`, `Progress.Label`, `Progress.Value`, `Progress.Track`.

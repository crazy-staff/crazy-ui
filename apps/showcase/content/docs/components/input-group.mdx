## Accessibility

- The input is a native `<input>`; the add-ons are plain text next to it. Name the input with `aria-label`, a
  `Label` or a `Field`, since an icon or a prefix doesn't name it.
- Buttons in an add-on need their own `aria-label` when they only show an icon.
- The frame takes the focus border while the input inside is focused.

## API Reference

### InputGroup

The short form: a frame with optional add-ons around the input. Other props (`placeholder`, `value`, `type`,
`disabled`, `readOnly`…) go to the input.

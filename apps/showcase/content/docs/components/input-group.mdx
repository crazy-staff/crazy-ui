```tsx
<InputGroup start={<Search />} end={<Kbd size="sm">K</Kbd>} placeholder="Search items…" />

// compound
<InputGroup.Root>
  <InputGroup.Addon>https://</InputGroup.Addon>
  <InputGroup.Input placeholder="crazy-hub.dev" />
</InputGroup.Root>
```

| Prop | Type | Default |
| --- | --- | --- |
| `start`, `end` | `ReactNode` | — |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `classNames` | `{ root, input, start, end }` | — |

The frame takes the focus border when the input inside is focused.

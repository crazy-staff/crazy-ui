## Accessibility

- The code area is focusable (`tabIndex=0`) so keyboard users can scroll long lines.
- The copy button is labelled "Copy code" and changes to "Copied".
- The fold buttons report `aria-expanded`.
- Colours follow the page: tokens use `light-dark()`, switched by `.dark` through `color-scheme`.

## Usage

```tsx
import { Radio, RadioGroup } from '@crazy-staff/ui';
```

```tsx
<RadioGroup
  defaultValue="normal"
  items={[
    { value: 'easy', label: 'Easy' },
    { value: 'normal', label: 'Normal' },
  ]}
/>
```

## Accessibility

- Renders `role="radiogroup"` with `role="radio"` items and a hidden native input for forms.
- <Kbd>Tab</Kbd> moves into the group (to the checked item), arrow keys move and select inside it.
- Name the group with `aria-label` or `aria-labelledby`; each item is named by its label.
- For more than about six options, or when space is tight, use a [Select](/docs/components/select).

### Radio

One option. With `label` it renders a clickable `<label>` row; without it, the bare circle (name it with
`aria-label`). Base UI `Radio.Root` props pass through.

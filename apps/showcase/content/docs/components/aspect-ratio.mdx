## Usage

```tsx
import { AspectRatio } from '@crazy-staff/ui';
```

```tsx
<AspectRatio ratio={16 / 9} rounded>
  <img src={screenshot} alt="The valley at dusk" />
</AspectRatio>
```

## Examples

### Ratios

`ratio` is width divided by height: `16 / 9` for screenshots and video, `4 / 3` for older captures, `1`
for squares. An `<img>` or `<video>` directly inside fills the box and is cropped to it.

<ComponentPreview name="aspect-ratio/ratios" />

### Video

Overlay a play button on a poster image; the box keeps its shape before and after the player loads.

## Accessibility

- The box is a plain `<div>` with no role. The media inside carries the meaning: give images an `alt`
  (empty `alt=""` when they are decoration) and videos captions.
- Controls laid over media (like a play button) need an accessible name.

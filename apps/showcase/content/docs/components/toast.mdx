## Usage

Mount `<Toaster />` once, near the root of the app. Then call `toast()` from anywhere — an event handler, a
mutation callback, outside React.

```tsx
import { Toaster, toast } from '@crazy-staff/ui';
```

```tsx
// root layout
<Toaster />

// anywhere
toast.success('Kit saved');
```

## Examples

### Types

`toast()` for a plain message, `toast.success`, `toast.info`, `toast.warning`, `toast.error`, and
`toast.loading` (which stays until you update or close it). The type sets the icon and how urgently screen
readers announce it.

### Description

A second line under the title for the details.

<ComponentPreview name="toast/description" />

### Action

`actionProps` adds a button — the classic Undo. `toast()` returns the toast's id, so the action can close it.

<ComponentPreview name="toast/action" />

### Promise

`toast.promise` shows a loading toast and turns it into a success or error one when the promise settles. Each
state takes a string, options, or (for success and error) a function of the result. This one fails sometimes on
purpose.

<ComponentPreview name="toast/promise" />

### Updating a toast

Keep the id from `toast.loading` and change the toast with `toast.update` as the work goes on.

<ComponentPreview name="toast/update" />

### Timeout

`timeout` sets how long a toast stays, in milliseconds; `0` keeps it until it is closed. The `Toaster` sets the
default for all toasts.

<ComponentPreview name="toast/timeout" />

### High priority

`priority: 'high'` makes screen readers interrupt to announce it. Keep it for things that need attention now.

<ComponentPreview name="toast/priority" />

## Accessibility

- The stack is a labelled region (<kbd>F6</kbd> moves focus into it). Each toast is announced through a live
  region: politely by default, assertively with `priority: 'high'`.
- Timers pause while the stack is hovered or focused, and while the window is in the background.
- Swipe down or right, or use the close button (`aria-label="Close"`), to dismiss.
- Don't put the only way to do something in a toast — it disappears. An Undo action is fine; a required step
  is not.

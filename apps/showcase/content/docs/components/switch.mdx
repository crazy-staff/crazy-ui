## Accessibility

- Renders a `<button role="switch">` with `aria-checked`, plus a hidden checkbox input for forms.
- <Kbd>Space</Kbd> and <Kbd>Enter</Kbd> toggle it.
- With `label`, the row is a `<label>`, so clicking the text toggles the switch and the text is its name.
  Without it, add `aria-label` or `aria-labelledby`.
- Use a switch for settings that apply at once. For a choice that is only saved on submit, a
  [Checkbox](/docs/components/checkbox) reads better.

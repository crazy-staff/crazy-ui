## Usage

```tsx
import { ChoiceField } from '@crazy-staff/ui';
```

```tsx
<ChoiceField
  label="Theme"
  value={theme}
  onValueChange={setTheme}
  choices={[
    { value: 'light', label: 'Light', icon: <Sun /> },
    { value: 'dark', label: 'Dark', icon: <Moon /> },
    { value: 'system', label: 'System', icon: <Monitor /> },
  ]}
/>
```

## Accessibility

- The toggle is a `group` named by `label`, with `aria-pressed` buttons.
- The button is named by `label` and shows the current choice; the drawer is a dialog titled by `label`.
  Picking closes it and focus returns to the button.

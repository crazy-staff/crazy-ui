## Accessibility

- `ariaLabel` (required) names the chart; add `ariaDescription` for the takeaway.
- The chart is focusable; arrow keys move between points and the tooltip follows, like the pointer.
- Colour is not the only cue: the legend and tooltip name each series. Offer a table for exact values.
- Animations respect reduced motion.

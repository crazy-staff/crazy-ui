## Usage

```tsx
import { Chart } from '@crazy-staff/ui';
```

```tsx
<Chart type="area" data={weeks} x="week" series={[{ key: 'votes', label: 'Votes' }]} ariaLabel="Votes per week" />
```

One row per category (week, build, day…) with one field per series. The width follows the container and
the height is fixed (`height`, 280 by default), so the chart is responsive on its own: x labels thin out
when there is no room for all of them.

## Examples

### Line

Several series share the palette: the accent first, then calmer colours derived from it. `points` adds
dots on every value.

<ComponentPreview name="chart/line" />

### Curve

`curve="smooth"` (the default) draws a monotone curve: smooth, but it never overshoots, so a peak in the
data stays the peak of the line and a dip never goes below its value. `curve="linear"` draws straight
segments, better for few points or when each step matters.

<ComponentPreview name="chart/curve" />

### Area with gradient

Areas fill with the series colour fading to transparent towards the baseline; overlapping series stay
readable because the fill is light where they meet.

<ComponentPreview name="chart/area" />

### Gradient under a line

`gradient` adds the same fill under a `line` chart; on bars it shades each bar from full colour to a lighter
foot.

<ComponentPreview name="chart/gradient-line" />

### Legend

With more than one series the legend shows, and each item toggles its series (the last visible one stays
on). Colours stay with their series while others are hidden. `defaultHiddenSeries` hides some at first;
`hiddenSeries` with `onHiddenSeriesChange` controls it.

<ComponentPreview name="chart/legend" />

### Crosshair and tooltip

Hovering (or moving with the arrow keys) shows a crosshair at the nearest x and a tooltip with every
visible series at that x. `tooltip={false}` turns both off.

<ComponentPreview name="chart/tooltip" />

### Dates and compact numbers

Dates on the x axis are formatted with `xFormat` (`day`, `week`, `month`, `year`, `Intl.DateTimeFormat`
options or a function). `valueFormat="compact"` writes 11300 as 11.3K. Both apply to the axis and the
tooltip; `locale` sets the language (`en-US` by default).

<ComponentPreview name="chart/format-dates" />

### Percentages

`valueFormat="percent"` expects fractions, like `Intl`: 0.979 is shown as 97.9 %. Pass
`Intl.NumberFormat` options or a function for anything else.

<ComponentPreview name="chart/format-percent" />

### Stacked bars

`stacked` stacks the series; only the top of each stack is rounded. The tooltip adds a total.

<ComponentPreview name="chart/stacked-bar" />

### Grouped bars

Without `stacked`, bars of one category stand side by side. Here with `gradient` and the legend under the
chart (`legendPosition="bottom"`).

<ComponentPreview name="chart/grouped-bar" />

### Stacked areas

`stacked` works for areas too: each layer starts where the one below ends.

<ComponentPreview name="chart/stacked-area" />

### Stacked to 100 %

`stacked="percent"` stacks each series' share of the total, with a 0–100 % axis. The tooltip shows the
value and its share.

<ComponentPreview name="chart/stacked-percent" />

### Reference line

`referenceLines` draws dashed horizontal lines for goals, limits or averages, with an optional label. The
y axis grows to include them.

<ComponentPreview name="chart/reference-line" />

### Loading

`loading` shows a skeleton of the same height, so nothing jumps when the data arrives.

<ComponentPreview name="chart/loading" />

### Empty

With no rows the chart shows an empty state; `empty` sets its title, description and action.

<ComponentPreview name="chart/empty" />

### Animation

On mount, lines and areas grow from the baseline and bars rise; changing data or toggling a series
animates to the new shape. With reduced motion the chart appears at once. `animate={false}` turns it off.

<ComponentPreview name="chart/animation" />

### Palette

Six colours, each overridable with a `--cui-chart-N` variable; after six they repeat. A series can also
take its own `color`.

<ComponentPreview name="chart/palette" />

## Accessibility

- `ariaLabel` (required) names the chart; add `ariaDescription` for the takeaway.
- The chart is focusable; arrow keys move between x values and the tooltip follows, like the pointer.
  The tooltip text is announced through a live region.
- The legend items are toggle buttons (`aria-pressed`).
- Colour is not the only cue: the legend and tooltip name each series. Offer a table for exact values.
- The entrance animation respects reduced motion.

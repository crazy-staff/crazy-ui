## Usage

```tsx
import { Tabs } from '@crazy-staff/ui';
```

```tsx
<Tabs
  items={[
    { value: 'character', label: 'Character', content: <CharacterCheats /> },
    { value: 'world', label: 'World', content: <WorldCheats /> },
  ]}
/>
```

`variant="line"` underlines the active tab instead of filling it. Use it for sections of a page, like
the Command / Manual switch under Installation above. Tabs still get a soft hover fill.

## Accessibility

- Built on Base UI Tabs: the list has `role="tablist"`, each tab `role="tab"` with `aria-selected`, and each
  panel `role="tabpanel"` linked to its tab.
- <kbd>←</kbd> <kbd>→</kbd> move between tabs (<kbd>↑</kbd> <kbd>↓</kbd> with `orientation="vertical"`),
  <kbd>Home</kbd> and <kbd>End</kbd> jump to the ends, disabled tabs are skipped.
- With `activateOnFocus` on `Tabs.List`, moving the focus also switches the panel.
- The panel animation, the gliding fill and the gliding hover block turn off with `prefers-reduced-motion`.
- Tabs with only an icon need an `aria-label`.

### Tabs.List

The row of tabs. Two blocks glide in it: the active fill follows the selected tab, and one neutral hover
block follows the mouse or keyboard focus. The hover block hides on the active tab and never slides out of
it. Renders a `<div>`.

## Usage

```tsx
import { AlertDialog } from '@crazy-staff/ui';
```

```tsx
<AlertDialog
  trigger={<Button variant="danger">Delete post</Button>}
  title="Delete this post?"
  actionLabel="Delete"
  tone="danger"
  onAction={deletePost}
/>
```

## Accessibility

- The popup has `role="alertdialog"`, labelled by `AlertDialog.Title` and described by
  `AlertDialog.Description`.
- Focus is trapped inside and returns to the trigger on close. <kbd>Esc</kbd> cancels.
- A click on the backdrop does **not** close it: the user must choose.
- In the short form focus starts on Cancel, so a stray <kbd>Enter</kbd> never confirms a destructive action.

## API Reference

### AlertDialog

The short form: a title, a description, a Cancel and an action button. Other props go to Base UI's
[`AlertDialog.Root`](https://base-ui.com/react/components/alert-dialog) (`open`, `defaultOpen`,
`onOpenChange` …).

## Accessibility

- Built on Base UI ScrollArea: the viewport is a native scroll container, so wheel, touch, keyboard and
  screen readers work as usual.
- The viewport is focusable when it scrolls, so keyboard users can scroll it with the arrow keys; it shows
  a focus ring.
- Give a scrolling region a heading or an `aria-label` if it's a landmark of its own.

## Usage

```tsx
import { Kbd, KbdGroup } from '@crazy-staff/ui';
```

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

## Accessibility

- Renders a native `<kbd>`, which screen readers can announce as keyboard input.
- Spell keys the way users see them on their keyboard. For icon keys (<Kbd>↵</Kbd>, ⌘) add `aria-label`.
- A `Kbd` only shows the shortcut. Wire up the key handler yourself.

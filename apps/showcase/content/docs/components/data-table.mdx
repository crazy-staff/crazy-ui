## Usage

```tsx
import { createDataTableColumns, DataTable } from '@crazy-staff/ui';
```

```tsx
const col = createDataTableColumns<Post>();
const columns = col.columns([col.accessor('title', { header: 'Idea' }), col.accessor('votes', { header: 'Votes' })]);

<DataTable columns={columns} data={posts} getRowId={(p) => p.id} selectable />
```

## Accessibility

- Sorted headers set `aria-sort`; sort buttons are real buttons.
- Selection checkboxes are labelled ("Select row", "Select all rows on this page"); Shift-click selects a range.
- The count is a polite live region, so filtering and selection are announced.
- Keep `columns` and `data` stable (module scope or `useMemo`).

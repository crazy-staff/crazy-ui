## Accessibility

- Built on Base UI Collapsible: the trigger is a `<button>` with `aria-expanded` and `aria-controls`
  pointing at the panel.
- <kbd>Enter</kbd> and <kbd>Space</kbd> toggle it.
- The chevron is decorative (`aria-hidden`). A trigger without text needs an `aria-label`.
- The height animation turns off with `prefers-reduced-motion`.

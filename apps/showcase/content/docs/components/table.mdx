## Usage

```tsx
import { Table } from '@crazy-staff/ui';
```

```tsx
<Table
  columns={[
    { key: 'name', header: 'Feature' },
    { key: 'hotkey', header: 'Hotkey' },
  ]}
  rows={[{ name: 'God mode', hotkey: 'F2' }]}
/>
```

### Compound parts

`Table.Root`, `Table.Header`, `Table.Body`, `Table.Footer`, `Table.Row`, `Table.Head`, `Table.Cell` and
`Table.Caption` map to the HTML table elements — for footers, `colSpan` and anything the short form
can't do.

For sorting, filtering and selection, build on TanStack Table with these parts.

## Accessibility

- Renders a real `<table>`: screen readers announce rows, columns and headers.
- Header cells are `<th>`; add `scope="row"` to a `Table.Head` that heads a row.
- Give the table a name with `caption` (or `aria-label` on `Table.Root`).
- The frame scrolls sideways when the table is wider than the screen; set a `min-w-*` on the table so
  columns don't squash.

## API Reference

### Table

The one-line form. Other props (`hover`, `dense`, `className`…) go to `Table.Root`.

<TypeTable
  type={{

    },
    rows: { description: 'The data, one object per row.', type: 'Row[]' },
    rowKey: { description: 'A stable key per row.', type: '(row, index) => Key', default: 'index' },

### Table.Root

The frame and the table. Renders a `<div>` around a `<table>`; other props go to the `<table>`.

## Usage

```tsx
import { Breadcrumb } from '@crazy-staff/ui';
```

```tsx
<Breadcrumb
  items={[
    { label: 'Gothic 1', href: '/gothic-1' },
    { label: 'Character', href: '/gothic-1/character' },
    { label: 'God mode' },
  ]}
/>
```

### Router links

`renderLink` turns every link into your router's link (here TanStack Router). With the parts, pass
`render` to `Breadcrumb.Link`.

```tsx
import { Link } from '@tanstack/react-router';

<Breadcrumb items={items} renderLink={(item) => <Link to={item.href} />} />

<Breadcrumb.Link render={<Link to="/docs" />}>Docs</Breadcrumb.Link>
```

## Accessibility

- Renders a `<nav aria-label="Breadcrumb">` with an ordered list, so screen readers announce the trail and
  its length.
- The last item is the current page: `aria-current="page"`, not a link.
- Separators are `aria-hidden` and `role="presentation"`.
- A button that reveals hidden levels needs an `aria-label` (“More pages”).

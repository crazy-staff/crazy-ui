## Examples

### Shapes

`line` (default) is a line of text, `block` a button or a thumbnail, `circle` an avatar and `card` a whole
card. Set the size with classes.

<ComponentPreview name="skeleton/shapes" />

### Lines of text

`lines` fakes a paragraph; the last line is shorter, like real text.

<ComponentPreview name="skeleton/lines" />

### A loading list

Copy the layout of the real rows — here the crazy-hub post list with a vote box — so nothing jumps when the

### Swapping in the content

Render skeletons while loading and the content after. Keep the sizes close, so the page doesn't shift.

## Accessibility

- Skeletons are `aria-hidden`: they mean nothing to a screen reader.
- Tell assistive tech that something loads in another way, e.g. `aria-busy="true"` on the region that is
  loading, or a visually hidden “Loading posts…” text.
- The shimmer stops with `prefers-reduced-motion`; the grey shape stays.

## API Reference

Renders a `<span>` (or a column of them with `lines`). Other props go to the span.

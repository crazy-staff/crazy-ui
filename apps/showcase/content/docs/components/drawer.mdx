## Accessibility

- A modal dialog (Base UI `Drawer`): `role="dialog"`, labelled by `Drawer.Title`, described by
  `Drawer.Description`. Always give it a title.
- Focus is trapped inside and returns to the trigger on close.
- <kbd>Esc</kbd>, a click on the backdrop and a swipe down close it. The handle is decorative; don't make swiping
  the only way out — add a Close button for long content.
- The slide follows the motion tokens, so reduced motion turns it off.

## Accessibility

- Renders a `<button>` with `aria-pressed`. <Kbd>Space</Kbd> and <Kbd>Enter</Kbd> toggle it.
- Keep the label the same in both states (“Pin”, not “Pin” / “Unpin”): `aria-pressed` already says whether it
  is on.
- The focus outline is drawn outside the button with `outline`, not a ring, so the squircle polyfill doesn't
  fill a transparent toggle.

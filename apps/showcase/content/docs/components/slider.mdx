## Accessibility

- Each thumb is an `<input type="range">` (visually hidden) inside the thumb element, so it has
  `role="slider"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`.
- Arrow keys move by `step`, <Kbd>Shift</Kbd> + arrow and <Kbd>Page Up</Kbd>/<Kbd>Page Down</Kbd> by
  `largeStep`, <Kbd>Home</Kbd>/<Kbd>End</Kbd> jump to the ends.
- `label` names the slider. Without it, pass `aria-label` (or `getAriaLabel` for ranges) to the root.

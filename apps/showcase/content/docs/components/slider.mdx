```tsx

```

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `ReactNode` | — |
| `showValue` | `boolean` | `false` |
| `value`, `defaultValue` | `number \| number[]` | — |
| `min`, `max`, `step` | `number` | `0`, `100`, `1` |
| `classNames` | `{ root, track, indicator, thumb }` | — |

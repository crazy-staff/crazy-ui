## Accessibility

- The image gets `alt={name}`. Without an image the initials carry `aria-label={name}`, so screen readers
  read the full name, not the letters.
- A status dot is decorative: say the status in text next to the avatar (as in the example) as well.
- In a group, list the names somewhere (a tooltip or a “voted by” list) — overlapping pictures alone
  don't tell who is there.

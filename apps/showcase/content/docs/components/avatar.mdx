## Props

| Prop | Type | Default |
| --- | --- | --- |
| `name` | `string` | — (alt text and initials) |
| `src` | `string` | — |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |

Parts: `Avatar.Root`, `Avatar.Image`, `Avatar.Fallback`. `initials(name)` is exported too.

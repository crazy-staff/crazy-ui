## Usage

```tsx
import { SidePanel, SidePanelButton, SidePanelSection, useSidePanel } from '@crazy-staff/ui';
```

```tsx
const panel = useSidePanel('idea-moderation');
const content = (
  <SidePanelSection label="Status" icon={<Tag />}>
    <Select … />
  </SidePanelSection>
);

<header>
  <h1>{idea.title}</h1>
  <SidePanelButton panel={panel} title="Moderation" icon={<Shield />}>
    {content}
  </SidePanelButton>
</header>
<aside>
  <SidePanel panel={panel} title="Moderation">
    {content}
  </SidePanel>
</aside>
```

- On a wide screen (`(min-width: 1024px)` by default) the button shows or hides the panel in the right
  column. It looks pressed while the panel is open, and the choice is remembered per `id` in this browser.
- On a narrow screen it opens the same content in a drawer, where the controls render at touch size.
- No floating "show panel" buttons: the panel always opens from the page's own controls.

## Usage

```tsx
import { Calendar } from '@crazy-staff/ui';
```

```tsx
const [date, setDate] = useState<Date | null>(new Date());

<Calendar value={date} onValueChange={setDate} />
```

## Examples

### Range

Set `mode="range"`: the first click picks the start, the second the end (in either order). While you
choose the end, the band follows the pointer. `numberOfMonths` shows months side by side.

<ComponentPreview name="calendar/range" />

### Disabled dates

`min` and `max` limit the range, `disabledDates` takes a list of days or a function. Disabled days can
still be focused with the keyboard, so screen reader users hear why they are skipped.

<ComponentPreview name="calendar/disabled-dates" />

### Locale and week start

Month and weekday names come from `Intl`, so any `locale` works without a date library. The week starts
on Monday; set `weekStartsOn={0}` for Sunday. `showOutsideDays={false}` hides the neighbouring months.

<ComponentPreview name="calendar/locale" />

## Accessibility

- Each month is a `grid` labelled with its name; weekday headers carry the full day name.
- Days are buttons with the full date as their name (`Friday, November 13, 2026`). Today has
  `aria-current="date"`, picked days `aria-selected`, unavailable days `aria-disabled`.
- One day is in the tab order. **Arrow keys** move by day and week, **Home** / **End** to the start and
  end of the week, **Page Up** / **Page Down** by month, with **Shift** by year. **Enter** or **Space**
  picks the day.
- The month change is announced through a polite live region. The slide animation is skipped with
  reduced motion.
- The root is a `group` named "Calendar"; pass `aria-label` to say what the date is for.

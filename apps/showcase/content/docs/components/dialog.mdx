## Usage

```tsx
import { Dialog } from '@crazy-staff/ui';
```

```tsx
<Dialog
  trigger={<Button>Edit kit</Button>}
  title="Edit kit"
  footer={<Dialog.Close render={<Button />}>Save</Dialog.Close>}
>
  …
</Dialog>
```

## Examples

### Sizes

`sm`, `md` (default) and `lg` set the maximum width. On a phone every size fills the screen minus a small margin.

### With a form

Control the dialog with `open` and `onOpenChange`, put a `<form>` inside `Dialog.Content`, and close it on
submit. The submit button is a plain `Button`; Cancel is a `Dialog.Close`.

### Compound parts

`Dialog.Root`, `Trigger`, `Content`, `Header`, `Title`, `Description`, `Body`, `Footer` and `Close` give you full
control. `showClose={false}` hides the corner close button.

## Accessibility

- The popup has `role="dialog"` and `aria-modal`, labelled by `Dialog.Title` and described by
  `Dialog.Description`. Always give a dialog a title.
- Focus moves into the dialog on open, stays trapped inside it, and returns to the trigger on close.
- <kbd>Esc</kbd> and a click on the backdrop close it; the page behind can't be scrolled.
- The corner close button has `aria-label="Close"`.

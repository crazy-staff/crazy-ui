## Examples

### Staggered group

`Reveal.Group` reveals its `Reveal.Item` children one after another — cards in a grid, rows in a list. `stagger`
sets the gap between two items in seconds.

<ComponentPreview name="reveal/group" />

### Delay

`delay` holds an element back, so a heading, its text and a button arrive in order.

<ComponentPreview name="reveal/delay" />

### Every time it scrolls in

By default an element animates only the first time. `once={false}` plays it again whenever it comes back into
view — scroll the box.

<ComponentPreview name="reveal/on-scroll" />

## Accessibility

- With `prefers-reduced-motion: reduce`, `Reveal` renders a plain `motion.div` with no animation: content is
  there at once.
- Content is in the DOM from the start (only its opacity and position change), so screen readers and search
  read it right away.

## API Reference

### Reveal

Fades and lifts its content in when it enters the viewport. Renders a `motion.div`; other
[motion props](https://motion.dev/docs/react-motion-component) go to it.

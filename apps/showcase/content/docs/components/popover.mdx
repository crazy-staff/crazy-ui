## Usage

```tsx
import { Popover } from '@crazy-staff/ui';
```

```tsx
<Popover trigger={<Button variant="outline">About this build</Button>} title="Build 0.9">
  Teleports, item kits and a fix for the arena crash.
</Popover>
```

## Accessibility

- The trigger gets `aria-expanded` and `aria-controls`; the popup is a `dialog` labelled by `Popover.Title` and
  described by `Popover.Description`.
- Focus moves into the popover when it opens and back to the trigger when it closes. <kbd>Esc</kbd> and a click
  outside close it.
- It is not modal by default: the page stays usable. Pass `modal` to trap focus and block the page.

## API Reference

### Popover

The short form: a trigger plus the floating panel with an optional title and description. Other props go to
Base UI's [`Popover.Root`](https://base-ui.com/react/components/popover) (`open`, `defaultOpen`, `onOpenChange`,
`modal` …).

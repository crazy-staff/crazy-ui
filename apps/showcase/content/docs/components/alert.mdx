## Usage

```tsx
import { Alert } from '@crazy-staff/ui';
```

```tsx
<Alert title="New build available">Version 0.9 adds teleports and fixes the arena crash.</Alert>
```

## Examples

### Variants

Five variants: `info` (default), `success`, `warning`, `danger` and `neutral`. Colours are muted on purpose,
so a page with several alerts doesn't shout.

<ComponentPreview name="alert/variants" />

### Without a title

Leave out `title` and the children become the whole message.

<ComponentPreview name="alert/description-only" />

### Custom icon

Every variant has its own icon. Pass any element to `icon` to replace it, or `false` to hide it.

<ComponentPreview name="alert/custom-icon" />

### With an action

Put a button (or a link) in the children.

<ComponentPreview name="alert/action" />

### Compound parts

Use `Alert.Title` and `Alert.Description` when you need to style or wrap the parts yourself.

## Accessibility

- `danger` and `warning` render with `role="alert"`, so screen readers announce them right away.
- The other variants use `role="status"` and are read politely.
- The icon is decorative (`aria-hidden`); the text carries the meaning.

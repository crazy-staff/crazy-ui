```tsx
<Alert variant="warning" title="Works badly">Save before using polymorph.</Alert>
```

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `'info' \| 'success' \| 'warning' \| 'danger' \| 'neutral'` | `'info'` |
| `title` | `ReactNode` | — |
| `icon` | `ReactNode \| false` | the variant's icon |
| `classNames` | `{ icon, body, title, description }` | — |

`danger` and `warning` use `role="alert"`, the others `role="status"`.

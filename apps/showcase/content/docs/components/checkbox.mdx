## Accessibility

- Renders a `<span role="checkbox">` with `aria-checked` (`mixed` when indeterminate) and a hidden native input
  for forms.
- <Kbd>Space</Kbd> toggles it.
- With `label`, the row is a `<label>`: clicking the text toggles the box. Without it, add `aria-label` or
  `aria-labelledby`.
- Name a `CheckboxGroup` with `aria-labelledby` (or wrap it in a fieldset with a legend).

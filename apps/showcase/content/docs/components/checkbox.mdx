```tsx
<Checkbox label="Remember me" defaultChecked />

<CheckboxGroup value={value} onValueChange={setValue}>
  <Checkbox value="esp" label="ESP" />
  <Checkbox value="radar" label="Radar" />
</CheckboxGroup>
```

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `ReactNode` | — |
| `checked`, `defaultChecked`, `onCheckedChange` | Base UI props | — |
| `indeterminate` | `boolean` | `false` |
| `classNames` | `{ root, indicator, label }` | — |

Compound parts: `Checkbox.Root`, `Checkbox.Indicator` (unstyled Base UI parts).

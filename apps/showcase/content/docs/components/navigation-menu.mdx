## Usage

```tsx
import { NavigationMenu } from '@crazy-staff/ui';
```

```tsx
<NavigationMenu
  items={[
    { label: 'Trainer', links: [{ title: 'Install', href: '/docs/install', description: 'Copy the DLL.' }] },
    { label: 'Changelog', href: '/changelog' },
  ]}
/>
```

## Examples

### Custom panel content

Give an item `content` to put anything in its panel. The floating box resizes smoothly between panels,
and panels slide in from the side the pointer came from. `active` marks the current page link.

<ComponentPreview name="navigation-menu/custom-content" />

### Compound parts

Use `NavigationMenu.Root`, `List`, `Item`, `Trigger`, `Content`, `Link`, `LinkCard` and `Viewport`.
Pass `render` to `Link` to use your router's link component.

<ComponentPreview name="navigation-menu/compound" />

## Accessibility

- Built on Base UI Navigation Menu: the root is a `<nav>` (name it with `aria-label`), triggers are
  buttons with `aria-expanded`, panels open on hover, click, **Enter** or **Space**.
- **Tab** moves through triggers and links; **Esc** closes the panel. The active link gets
  `aria-current="page"`.
- The gliding highlight and the panel slide are decorative; with reduced motion they don't move.

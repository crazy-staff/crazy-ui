## Props

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` |
| `tone` | `'accent' \| 'muted' \| 'current'` | `'accent'` |
| `label` | `string` | `'Loading'` |

With reduced motion it keeps turning, slowly — a frozen spinner would look like a hang.

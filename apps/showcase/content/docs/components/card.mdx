## Usage

```tsx
import { Card } from '@crazy-staff/ui';
```

```tsx
<Card title="Infinite mana" description="Keeps your mana pool full." footer={<Button size="sm">Enable</Button>}>
  Works in every chapter.
</Card>
```

## Accessibility

- A card is a plain `<div>`; `Card.Title` is an `<h3>`, so cards in a list show up in the heading outline.
  If `h3` is the wrong level, put your own heading in `Card.Header` instead of `Card.Title`.
- An `interactive` card is only styled as one. Make it reachable: wrap it in a link, or give it `tabIndex={0}`
  and a keyboard handler.

## API Reference

### Card

The short form. With `title`, `description` or `footer` it builds the header, body and footer for you; without
them it is just the surface and `children` render as they are. Renders a `<div>`.

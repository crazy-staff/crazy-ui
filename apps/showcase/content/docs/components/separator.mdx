## Accessibility

- Built on Base UI Separator: renders `role="separator"` with `aria-orientation`.
- A separator is not focusable and has no name. If the line is only decoration, that's fine; if it
  splits sections, give the sections headings too.
- With a label, the text is read normally and the two lines around it are separators.

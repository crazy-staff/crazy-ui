## Usage

```tsx
import { Pagination } from '@crazy-staff/ui';
```

```tsx
const [page, setPage] = useState(1);

<Pagination page={page} total={20} onPageChange={setPage} />;
```

## Examples

### Jumping far

The bar always has the same number of slots, so it can move like a strip of numbers. When the page jumps,
the highlight first glides to the number you clicked, then the numbers roll from their old values to the
new ones — faster the more pages they pass — and the highlight settles on the new page. With
`prefers-reduced-motion` the page changes at once.

### Building your own

`paginationRange(page, total, siblings)` returns the slots the bar shows: page numbers and `'ellipsis'`
for the gaps. Use it for a custom layout.

```tsx
import { paginationRange } from '@crazy-staff/ui';

paginationRange(1, 20); // [1, 2, 3, 4, 5, 'ellipsis', 20]
paginationRange(10, 20); // [1, 'ellipsis', 9, 10, 11, 'ellipsis', 20]
```

## Accessibility

- Renders a `<nav aria-label="Pagination">` with a list of buttons.
- Every number has `aria-label="Page n"`; the current one has `aria-current="page"` right away, even while
  the numbers still roll on screen (the rolling digits are `aria-hidden`).
- Previous and Next are labelled and disabled on the first and last page.
- Gaps are `aria-hidden`; they are not buttons.
- After a page change, move the focus or announce the new results if they load somewhere else on the page.

### paginationRange

The slots for a page: first, last, the current page with its siblings, and `'ellipsis'` for the gaps. The
length is the same on every page (`siblings * 2 + 5`, or `total` when that is smaller).

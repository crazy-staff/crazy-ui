## Usage

```tsx
import { DropdownMenu } from '@crazy-staff/ui';
```

```tsx
<DropdownMenu
  trigger={<Button variant="outline">Kit options</Button>}
  items={[
    { label: 'Rename', shortcut: 'F2' },
    { type: 'separator' },
    { label: 'Delete', danger: true, onClick: remove },
  ]}
/>
```

## Accessibility

- The trigger gets `aria-haspopup="menu"` and `aria-expanded`; the popup is a `menu` with `menuitem`,
  `menuitemcheckbox` and `menuitemradio` entries.
- <kbd>Enter</kbd>, <kbd>Space</kbd> or <kbd>↓</kbd> on the trigger opens the menu; arrow keys move, typing a
  letter jumps to the matching item, <kbd>Esc</kbd> closes and returns focus.
- Shortcuts are shown as text only. Bind the keys yourself.
- Icons are decorative; the label carries the meaning.

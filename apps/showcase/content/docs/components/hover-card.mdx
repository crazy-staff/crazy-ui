## Usage

```tsx

```

```tsx

```

## Accessibility

- Opens on hover and on keyboard focus of the trigger, after a short delay; closes when both the link and the
  card lose the pointer and focus.
- The card is a supplement: the link must work on its own (touch screens can't hover). Don't put the only
  copy of an action in it.
- Use a real link (`<a href>`) as the trigger.

## API Reference

### HoverCard

The short form: a trigger link and the card content. Other props go to Base UI's
[`PreviewCard.Root`](https://base-ui.com/react/components/preview-card) (`open`, `defaultOpen`,
`onOpenChange` …).

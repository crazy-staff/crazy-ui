```tsx

  …
</HoverCard>
```

| Prop | Type | Default |
| --- | --- | --- |
| `trigger` | `ReactElement` (usually a link) | — |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'` |
| `delay` | `number` (ms) | `500` |

Parts: `HoverCard.Root`, `.Trigger`, `.Content`. Built on Base UI's Preview Card. Don't put anything people must
reach only here — touch screens never hover.

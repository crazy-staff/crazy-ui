## Sizes and glow

<Preview align="start">
  <ButtonSizes />
</Preview>

`glow` adds a soft accent shadow under a solid button. It is **off by default** — keep it for the one main
action on a screen.

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `'solid' \| 'soft' \| 'outline' \| 'ghost' \| 'danger'` | `'solid'` |
| `size` | `'sm' \| 'md' \| 'lg' \| 'icon' \| 'icon-sm'` | `'md'` |
| `glow` | `boolean` | `false` |
| `className` | `string` | — |

All other props go to Base UI's `Button` (a native `<button>`).

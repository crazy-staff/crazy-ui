## Examples

### Variants

`solid` (default) for the main action, `soft` for a secondary one that still carries the accent, `outline` and
`ghost` for quiet actions, `danger` for anything that deletes or resets.

<ComponentPreview name="button/variants" />

### Sizes

`sm`, `md` (default) and `lg`. Height comes from the density token and the radius shrinks with the size.

<ComponentPreview name="button/sizes" />

### With an icon

Put a lucide icon before or after the label; it is sized for you.

<ComponentPreview name="button/with-icon" />

### Icon only

`size="icon"` and `size="icon-sm"` make a square button. Always give it an `aria-label`.

<ComponentPreview name="button/icon" />

### Glow

`glow` adds a soft accent shadow under the button. It is off by default — keep it for the one main action on a
screen.

<ComponentPreview name="button/glow" />

### Disabled

A disabled button fades out and ignores clicks.

<ComponentPreview name="button/disabled" />

### Loading

Disable the button while the action runs and swap the icon for a `Spinner`. `aria-busy` tells screen readers
something is happening.

<ComponentPreview name="button/loading" />

### As a link

Pass an element to `render` to keep the button look on a link. Set `nativeButton={false}` when it is not a
`<button>`.

<ComponentPreview name="button/as-link" />

## Accessibility

- Renders a native `<button>` (Base UI `Button`), so <kbd>Enter</kbd> and <kbd>Space</kbd> work and it sits in
  the tab order.
- Focus shows a ring only for keyboard focus (`:focus-visible`).
- Icon-only buttons need an `aria-label`; the icon itself is decorative.
- `disabled` removes the button from the tab order. If people should still find it (to read a tooltip about
  why), use Base UI's `focusableWhenDisabled`.

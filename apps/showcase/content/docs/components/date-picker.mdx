## Usage

```tsx
import { DatePicker } from '@crazy-staff/ui';
```

```tsx
const [date, setDate] = useState<Date | null>(null);

<DatePicker value={date} onValueChange={setDate} placeholder="Release date" />
```

## Examples

### Range

`mode="range"` picks two days. The popover closes once both ends are set, and the trigger shows the range
formatted with `Intl.DateTimeFormat.formatRange` (`Nov 3 – 9, 2026`).

<ComponentPreview name="date-picker/range" />

### Sizes

`sm`, `md` (default) and `lg` match the sizes of Input.

<ComponentPreview name="date-picker/sizes" />

### In a form

With `name`, the value is submitted as `YYYY-MM-DD` (a range as `name[from]` and `name[to]`).
`formatOptions` changes how the trigger shows the date; `min`, `max`, `disabledDates`, `locale` and
`weekStartsOn` go to the calendar. `disabled` locks the trigger.

<ComponentPreview name="date-picker/form" />

## Accessibility

- The trigger is a button; its name is the shown date or the placeholder. Label it with `aria-label`,
  `aria-labelledby` or an `id` referenced by a label.
- Opening moves focus to the picked day (or today) inside the calendar; **Esc** closes and returns focus
  to the trigger. All [Calendar](/docs/components/calendar) keys work inside.

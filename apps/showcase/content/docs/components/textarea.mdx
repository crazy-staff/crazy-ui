```tsx
<Textarea placeholder="What happened?" />
<Textarea resize="none" rows={3} />
```

| Prop | Type | Default |
| --- | --- | --- |
| `resize` | `'vertical' \| 'none'` | `'vertical'` |

All other props go to the native `<textarea>`. Like inputs, it has no shadow (squircle polyfill rule).

## Accessibility

- The root is a `region` with `aria-roledescription="carousel"`; give it an `aria-label`.
- Each slide is a `group` with `aria-roledescription="slide"` and a label like "2 of 5".
- Left/Right (Up/Down when vertical) move between slides while focus is inside. Buttons and dots are labelled.
- With reduced motion, slides jump instead of scrolling.

## Usage

```tsx
import { NativeSelect } from '@crazy-staff/ui';
```

```tsx
<NativeSelect aria-label="Game" options={[{ value: 'g1', label: 'Gothic 1' }, { value: 'g2', label: 'Gothic 2' }]} />
```

### With a label and states

Use a `Label` with `htmlFor`. `disabled` dims the field, `aria-invalid` paints the border red, and
`placeholder` adds a hidden empty first option.

<ComponentPreview name="native-select/field" />

## Accessibility

- It is a real `<select>`: keyboard, screen readers and the phone's own picker work as usual.
- Give it a name with a `<label htmlFor>` or `aria-label`. The chevron is decorative.
- Pick [Select](/docs/components/select) when you need styled options or icons in the list.

## API Reference

### NativeSelect

Renders a `<span>` wrapper with a `<select>` and a chevron. Other props go to the `<select>`.

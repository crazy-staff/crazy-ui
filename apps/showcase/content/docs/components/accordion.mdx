## Usage

```tsx
import { Accordion } from '@crazy-staff/ui';
```

```tsx
<Accordion
  items={[
    { value: 'install', title: 'How do I install the trainer?', content: 'Copy the files into the Gothic folder.' },
    { value: 'saves', title: 'Will it break my saves?', content: 'No, saves stay compatible.' },
  ]}
/>
```

## Accessibility

- Built on Base UI Accordion: every trigger is a `<button>` inside a heading, with `aria-expanded` and
  `aria-controls` pointing at its panel; the panel has `role="region"` labelled by the trigger.
- <kbd>Enter</kbd> and <kbd>Space</kbd> toggle a section; <kbd>↑</kbd> <kbd>↓</kbd> move between triggers,
  <kbd>Home</kbd> and <kbd>End</kbd> jump to the first and last.
- Triggers sit in an `<h3>`, so the sections show up in the page outline. Put the accordion under an `h2`.
- The panel height and the chevron animate only without `prefers-reduced-motion`.

The one-line form. Renders `Accordion.Root` with an item per entry; other props go to the root.

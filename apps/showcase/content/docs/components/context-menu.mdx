```tsx
<ContextMenu items={[{ label: 'Copy', shortcut: 'Ctrl C' }, { type: 'separator' }, { label: 'Delete', danger: true }]}>
  <div>Right-click here</div>
</ContextMenu>
```

It shares items and look with [Dropdown Menu](/docs/components/dropdown-menu): `ContextMenu.Item`, `.CheckboxItem`,
`.RadioItem`, `.Separator`, `.Shortcut` … plus `ContextMenu.Root`, `.Trigger` and `.Content`.

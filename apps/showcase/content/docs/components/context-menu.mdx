## Usage

```tsx
import { ContextMenu } from '@crazy-staff/ui';
```

```tsx
<ContextMenu items={[{ label: 'Copy', shortcut: 'Ctrl C' }, { type: 'separator' }, { label: 'Delete', danger: true }]}>
  <div>Right-click here</div>
</ContextMenu>
```

## Accessibility

- Opens on right click, on long press on touch screens, and with the keyboard's context-menu key or
  <kbd>Shift</kbd> + <kbd>F10</kbd> when the area is focused.
- The popup is a `menu`; arrow keys move, type-ahead jumps, <kbd>Esc</kbd> closes.
- A context menu is hidden by nature. Every action in it must also be reachable another way (a visible button
  or a dropdown menu).

## API Reference

### ContextMenu

The short form: an area and a list of entries (the same `DropdownMenuEntry` as Dropdown Menu). Other props go
to Base UI's [`ContextMenu.Root`](https://base-ui.com/react/components/context-menu).

## Usage

```tsx

```

```tsx
<Menubar menus={[{ label: 'Profile', items: [{ label: 'Save', shortcut: 'Ctrl S' }] }]} />
```

## Examples

### Checkboxes, radios and submenus

The compound parts are the [Dropdown Menu](/docs/components/dropdown-menu) parts, so menus can hold
checkbox items, radio groups, group labels and submenus.

<ComponentPreview name="menubar/compound" />

## Accessibility

- Built on Base UI Menubar: the bar has `role="menubar"`, its buttons `role="menuitem"`.
- **Left/Right Arrow** move between menus (and open the next one while a menu is open), **Down Arrow**
  opens, **Esc** closes. Items work like in Dropdown Menu.
- Shortcuts are hints only; wire the keys yourself.

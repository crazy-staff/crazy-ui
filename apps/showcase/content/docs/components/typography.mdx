## Accessibility

- `Prose` only styles; use real headings in order (`h2` after `h1`), lists and tables so screen readers get the structure.
- `render` swaps the element but keeps the look: `<Typography.H2 render={<h3 />}>` for a correct outline.
- Links are underlined, not only coloured.

## Examples

### Multiple

With `multiple`, picked values become chips inside the field. Click the × on a chip, or move to it with
**Left Arrow** from the start of the input and press **Backspace**, to remove it.

<ComponentPreview name="combobox/multiple" />

### Groups and icons

Pass groups (`{ label, items }`) instead of a flat list. Items can carry an `icon` and be `disabled`.

<ComponentPreview name="combobox/groups" />

### Empty state

`emptyText` is shown when nothing matches the typed text.

<ComponentPreview name="combobox/empty" />

### Compound parts

Build the field yourself with `Combobox.Root`, `Combobox.InputGroup`, `Combobox.Input`, `Combobox.Content`
and `Combobox.Item` when you need custom rows (here: post titles with their votes).

## Accessibility

- Built on Base UI Combobox: the input has `role="combobox"`, the list `role="listbox"`, items
  `role="option"` with `aria-selected`.
- **Arrow keys** move through the list, **Enter** picks, **Esc** closes. The empty state is announced
  politely.
- Give the input a name: a `<label htmlFor>` with `id`, a `Field`, or `aria-label`. The clear, open and
  chip remove buttons have their own labels (`Clear`, `Open list`, `Remove …`).

### Combobox.Root

Base UI `Combobox.Root`; renders no element. All its props pass through (`items`, `multiple`, `filter`,
`itemToStringLabel`, `limit`, `open` …).

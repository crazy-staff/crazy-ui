## Usage

```tsx
import { Resizable } from '@crazy-staff/ui';
```

```tsx
<Resizable.Group>
  <Resizable.Panel defaultSize="30">Features</Resizable.Panel>
  <Resizable.Handle withHandle />
  <Resizable.Panel>Details</Resizable.Panel>
</Resizable.Group>
```

## Accessibility

- Each handle has `role="separator"` with `aria-valuenow`/`min`/`max`, is focusable and moves with the arrow keys (Home/End jump to the limits).
- Double-click a handle to reset its panel to the default size.
- Give panels with meaningful content a heading or a label so the split is understandable.

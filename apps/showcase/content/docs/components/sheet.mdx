```tsx

</Sheet>
```

## Examples

### Sides

`side` slides the panel in from the `right` (default), `left`, `top` or `bottom`. It floats a little away from
the window edge with the card radius, like the docs page panel.

<ComponentPreview name="sheet/sides" />

### Settings form

Control it with `open` and `onOpenChange` and put a `<form>` inside `Sheet.Content`. `Sheet.Body` grows, so the
footer sits at the bottom of the panel.

<ComponentPreview name="sheet/settings-form" />

### Navigation

A left sheet makes the mobile menu. Each link is a `Sheet.Close`, so picking one closes the panel.

<ComponentPreview name="sheet/navigation" />

## Accessibility

- A sheet is a modal dialog (Base UI `Dialog`): `role="dialog"`, labelled by `Sheet.Title`, described by
  `Sheet.Description`.
- Focus is trapped inside and returns to the trigger on close; the page behind can't be scrolled.
- <kbd>Esc</kbd>, the close button and a click on the backdrop close it.
- For a panel people drag closed on a phone, use a [Drawer](/docs/components/drawer).

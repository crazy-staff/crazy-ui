
| Prop | Type | Default |
| --- | --- | --- |
| `side` | `'right' \| 'left' \| 'top' \| 'bottom'` | `'right'` |
| `title`, `description`, `footer` | `ReactNode` | — |

Parts: `Sheet.Root`, `.Trigger`, `.Content` (`side`, `showClose`), `.Header`, `.Title`, `.Description`, `.Body`,
`.Footer`, `.Close`. Built on Base UI's Dialog.

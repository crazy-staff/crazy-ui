## Usage

```tsx
import { Tooltip } from '@crazy-staff/ui';
```

```tsx
<Tooltip content="Copy invite link">
  <Button size="icon" aria-label="Copy invite link">
    <Copy />
  </Button>
</Tooltip>
```

## Accessibility

- Opens on hover and on keyboard focus; <kbd>Esc</kbd> closes it.
- The tooltip text becomes the trigger's accessible description (`aria-describedby`), not its name. Icon-only
  triggers still need an `aria-label`.
- Never put the only copy of important information in a tooltip — touch screens can't hover.
- Opening is delayed by 400 ms so tooltips don't flash while the pointer crosses the page.

## API Reference

### Tooltip

The short form: wraps a trigger element and shows `content` next to it. Other props go to Base UI's
[`Tooltip.Root`](https://base-ui.com/react/components/tooltip) (`open`, `defaultOpen`, `onOpenChange`,
`disabled`, `trackCursorAxis`, `disableHoverablePopup` …).

### Tooltip.Provider

Shares timing between the tooltips inside it, so neighbours open instantly once one is showing. Renders nothing.

```tsx
<Tooltip content="Copy link">
  <Button size="icon" aria-label="Copy link"><Copy /></Button>
</Tooltip>
```

Wrap a toolbar in `Tooltip.Provider` so the next tooltip opens instantly once one is showing.

| Prop | Type | Default |
| --- | --- | --- |
| `content` | `ReactNode` | — |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'` |
| `delay` | `number` (ms) | `400` |

Parts: `Tooltip.Provider`, `Tooltip.Root`, `Tooltip.Trigger`, `Tooltip.Content`.

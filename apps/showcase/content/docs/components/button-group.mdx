## Usage

```tsx
import { Button, ButtonGroup } from '@crazy-staff/ui';
```

```tsx
<ButtonGroup aria-label="Map zoom">
  <Button variant="outline">−</Button>
  <Button variant="outline">+</Button>
</ButtonGroup>
```

## Accessibility

- Renders a `<div role="group">`. Name it with `aria-label` so screen readers announce what the buttons belong to.
- Each button keeps its own focus and name; icon-only buttons need `aria-label`.
- The focused button is lifted above its neighbours, so its focus ring is never covered.
- For buttons that stay pressed, use a [Toggle Group](/docs/components/toggle-group) instead.

## API Reference

### ButtonGroup

Joins its children: inner corners go square and neighbouring borders overlap by one pixel. Renders a
`<div role="group">`; native div props pass through.

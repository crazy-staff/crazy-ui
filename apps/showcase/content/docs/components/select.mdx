## Usage

```tsx
import { Select } from '@crazy-staff/ui';
```

```tsx
<Select
  placeholder="Pick a game"
  items={[
    { value: 'g1', label: 'Gothic 1' },
    { value: 'g2', label: 'Gothic 2' },
  ]}
/>
```

## Accessibility

- The trigger is a `role="combobox"` button; the popup is a `role="listbox"` with `role="option"` items.
- <Kbd>Enter</Kbd>, <Kbd>Space</Kbd> or <Kbd>↓</Kbd> open it; arrow keys move, typing jumps to a match,
  <Kbd>Enter</Kbd> picks and <Kbd>Esc</Kbd> closes.
- Name it with a `Field` label, `<Label htmlFor>` (with `id`), or `aria-label`.
- A hidden input carries the value for native forms (`name`, `required`).

### Select.Root

Holds the state. Renders no element. This is Base UI's `Select.Root`; all its props apply (`items`, `value`,
`defaultValue`, `onValueChange`, `open`, `onOpenChange`, `multiple`, `name`, `required`, `disabled`…).
